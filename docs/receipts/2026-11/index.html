Stale-Reference Receipts

An instruction file that names a path which no longer exists is not a style problem. It is a factual defect with a one-line fix. This page scans the context files of the most-starred repositories, reports the references that do not resolve, and states what was done about each one.

  • 23repositories scanned
  • 5references that did not resolve
  • 2confirmed defects after reading
  • 3read and excluded as examples

The scanner is deliberately conservative. It checks paths, globs, and npm run scripts named in a context file against the repository, and stays quiet when a reference could be a name, an example, or one of two alternatives. What it reports is still a candidate, not a verdict: every row below was read before it was called a defect, and receipts/reviews.json records the reading. The excluded list is published too, because a measurement that hides its false positives is not one.

How it was counted

  • Each repository's default branch was read through the GitHub API. The file tree was laid out as empty files, the context files were written with their real contents, and ctxcap --stale ran against that copy. Nothing was cloned and nothing was written to the repository.
  • A reference is reported only when it is spelled like a path into the repository and the path does not resolve. Identifiers, commands that are not npm run, routes, branches, and package names are not paths and are skipped.
  • An npm run script is judged only when every package.json in the tree was fetched; otherwise command findings are dropped rather than guessed.
  • Two repositories in the index are not here: GitHub truncates their file tree, so a missing path cannot be distinguished from an unlisted one.

Run it on a repository

npx ctxcap --stale          # every reference that does not resolve
npx ctxcap --stale-fix      # a deletion diff for the ones it is sure about

To send one in: open an audit issue with the repository. The series is time-boxed to ten, and the before and after are published here with the line that changed.
