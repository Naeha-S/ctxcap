What the most-starred repositories spend on agent instructions

An AGENTS.md or CLAUDE.md is read by a coding agent at the start of every session. Whatever it weighs is spent again each time, before the agent has looked at a line of code. This page counts that weight for the most-starred repositories on GitHub that have one.

  • 25 of 56most-starred repositories have one at the root
  • 45%hit rate, checking in star order
  • 1,034tokens in the median file, of 30 files
  • 6,249tokens in the largest

This is a sample, not a ranking of GitHub: it is the first 25 repositories with such a file, going down from the most stars. And a large file is not a bad file. Six thousand tokens of rules an agent needs are well spent. The table says what each file costs, not whether it is worth it.

How it was counted

  • The 56 most-starred repositories that are not archived were checked in star order, stopping at the 25th with a context file. Stopping on a hit slightly overstates the 45% rate.
  • Only files at the repository root are counted. Nested AGENTS.md and CLAUDE.md files, files these import, and other rule files are not.
  • A symlink is counted as the file it points to, because that is what an agent that opens it reads. AGENTS.md → README means the agent is given the README.
  • A file that is a copy of the one beside it, or that only imports it, is counted once. A repository with both files appears twice when they differ.
  • Tokens are counted with gpt-tokenizer@3.0.1 (OpenAI's o200k encoding). Other models tokenize differently, so read these as approximate and compare them with each other.
  • Fetched on 2026-11-15 from each repository's default branch. This is the first month, so there is nothing yet to compare against; changes appear from the next one.
