# The audit series

Ten repositories at most. Each audit is one numbered post: the token count
before, the plan, the edits, the count after, and the `ctxcap` output that
proves it. Nothing is changed in a repository without a pull request its
maintainer approves, and nothing is published without their say.

Request one with the [audit issue
form](https://github.com/Naeha-S/ctxcap/issues/new?template=audit.yml). One
repository per issue; first come, first served; the ten slots do not refill.
